# Crisis Fingerprint Portfolios

Interactive results page for a crisis-aware decision-focused portfolio model (DFL-MVO with a
Portfolio Coherence Image penalty) on the DOW 30, walk-forward 2013-2024.

The page is password protected: `index.html` holds the page and its data encrypted
(AES-256-GCM, PBKDF2-SHA256 key) and decrypts them in the browser.

The research code is not included.
